## 🚀 Quick Start (3 Steps)

### Step 1: Install Dependencies
Open PowerShell in this folder and run:
```powershell
npm install
```
⏱️ This takes 1-2 minutes

### Step 2: Start Development Server
```powershell
npm run dev
```
✅ Website opens automatically at http://localhost:3000

### Step 3: Make It Yours!
- Update text content in `src/pages/*.jsx`
- Add your images to `public/images/`
- Change colors in `tailwind.config.js`
- Update contact info in `src/components/Footer.jsx` and `src/pages/Contact.jsx`

## 🎨 Customization Quick Tips

### Change Colors
Edit `tailwind.config.js`:
```javascript
colors: {
  primary: { 
    600: '#your-color',  // Main brand color
    700: '#darker-shade'
  }
}
```

### Update Content
All content is in `src/pages/`:
- Open any page file (e.g., `Home.jsx`)
- Find the text you want to change
- Update and save
- Changes appear instantly in browser

### Add Images
1. Place images in `public/images/`
2. Use in components: `<img src="/images/your-image.jpg" />`

### Contact Information
Update in two places:
- `src/components/Footer.jsx` (footer contact section)
- `src/pages/Contact.jsx` (contact page)

## 🆘 Need Help?

### Resources:
- **React Docs:** https://react.dev
- **Tailwind CSS:** https://tailwindcss.com/docs
- **Framer Motion:** https://www.framer.com/motion/
- **Vite Guide:** https://vitejs.dev/guide/

### Common Issues:
1. **Dependencies won't install?** 
   - Make sure Node.js v18+ is installed
   
2. **Port 3000 busy?** 
   - Use: `npm run dev -- --port 3001`
   
3. **Dark mode not saving?** 
   - Clear browser cache and localStorage
