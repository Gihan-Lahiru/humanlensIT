🚀 GET STARTED IN 3 STEPS:
═══════════════════════════════════════════════════════════════════════

STEP 1: Install Dependencies
────────────────────────────────────────────────────────────────────
Open PowerShell in this folder and run:

    npm install

⏱️  This takes 1-2 minutes and only needs to be done once.


STEP 2: Start Development Server
────────────────────────────────────────────────────────────────────
After installation completes, run:

    npm run dev

✅ Your website will automatically open at http://localhost:3000
✅ Any changes you make will instantly appear in the browser!


STEP 3: Customize Your Content
────────────────────────────────────────────────────────────────────
• Edit text in src/pages/*.jsx files
• Add images to public/images/ folder
• Update contact info in Footer.jsx and Contact.jsx
• Change colors in tailwind.config.js (optional)

💡 QUICK TIPS:
═══════════════════════════════════════════════════════════════════════

Development:
• Keep "npm run dev" running while editing
• Changes auto-reload in browser
• Press Ctrl+C to stop the server
• Check browser console (F12) if something breaks

Content Updates:
• All page content is in src/pages/
• Search for text you want to change (Ctrl+Shift+F in VS Code)
• Save file and see changes instantly

Images:
• Put images in public/images/
• Reference as: <img src="/images/your-image.jpg" />
• Compress images before adding (use tinypng.com)

🆘 NEED HELP?
═══════════════════════════════════════════════════════════════════════

Common Issues:

Problem: "npm: command not found"
Solution: Install Node.js from https://nodejs.org (v18 or higher)

Problem: "Port 3000 is already in use"
Solution: Use different port: npm run dev -- --port 3001

Problem: "Dependencies won't install"
Solution: Delete node_modules and package-lock.json, then run npm install

Problem: "Website looks broken"
Solution: Clear browser cache (Ctrl+Shift+Delete) and refresh

For more help:
• Check documentation files listed above
• Read inline code comments
• Search error messages online
• Ask on Stack Overflow
