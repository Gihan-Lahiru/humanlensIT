# HumanLens  (Pvt) Ltd - IT Solutions Unit

A professional, modern, and responsive website built with React, Vite, and Tailwind CSS.

## Features

- 🎨 Modern and elegant design with Tailwind CSS
- 🌓 Dark/Light mode toggle
- 📱 Fully responsive layout
- ✨ Smooth animations with Framer Motion
- 🧭 Multi-page routing with React Router
- 🎯 Professional business presentation

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open your browser and navigate to `http://localhost:3000`

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## Project Structure

```
src/
├── components/        # Reusable components
├── pages/            # Page components
├── context/          # React context (theme, etc.)
├── App.jsx           # Main app component
├── main.jsx          # Entry point
└── index.css         # Global styles
```

## Pages

- **Home** - Introduction, Vision, Mission, and key highlights
- **About** - Background, Rationale, Objectives, and Organizational Structure

- **Marketing** - Marketing & Promotion Strategy
